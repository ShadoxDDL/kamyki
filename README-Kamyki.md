# Kamyki z podpisami SI

Natywny dodatek do panelu dodatków Gargonem. Wyświetla krótkie podpisy na kamieniach teleportacyjnych i pozwala ustawić rozmiar czcionki w zakresie 6–24 px.

Plik dodatku na GitHub Pages:

`https://shadoxddl.github.io/kamyki/Kamyki.js`

## Publikacja

1. Wgraj `Kamyki.js`, `Kamyki-loader.user.js` i ten plik do głównego katalogu repozytorium `ShadoxDDL/kamyki`.
2. W **Settings → Pages** wybierz **Deploy from a branch**, gałąź `main` oraz katalog `/(root)`.
3. Po publikacji zainstaluj `Kamyki-loader.user.js` w Tampermonkey.

Dodatek używa standardowego okna i trwałych ustawień Gargonem.
